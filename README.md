# Urological Procedure Digital Twin

This repository provides the public project description for the Michigan Technological University senior design project.

## Project description

[View the project-description PDF](project-description.pdf).

The description establishes the project context and intended problem area. The student team owns the detailed scope, technical choices, implementation, experiments, and evaluation used for its proof of concept.

## Team repositories

The working repositories are private because they may contain sponsor planning, budget, research, and progress information:

- `Project-Documents` — scope, infrastructure, budget, decisions, and risks
- `Weekly-Reports` — weekly team reports
- `Resources` — research notes, dataset metadata, model evaluations, and experiment logs

Access is managed through the [Urological Procedure Digital Twin organization](https://github.com/Urological-Procedure-Digital-Twin).
